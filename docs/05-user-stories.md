# User Stories

## User Registiration
As a junior developer, I want to create an account so that I can access and view my roadmap again later.

## CV Upload
As a junior developer, I want to upload my CV so that the system can analyze my current skilss and compare them with my target role.

## Skill Extraction
As a junior developer, I want to see my skill extraction results so that I can better understand my current competencies and strengths.

## Analysing Skill Gaps
As a junior developer, I want to identify my skill gaps so that I can focus on improving the competencies required for my target role.

## Personalized roadmap
As a junior developer, I want to receive a personalized roadmap so that I can understand which skill to prioritize and follow a structured learning path for my target role.
